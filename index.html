CHAPTER 1프롬프트 엔지니어링이란?
프롬프트(Prompt)가 뭐예요?
우리가 AI에게 질문하거나 명령하는 문장을 '프롬프트'라고 합니다.
🐱 고양이 그림 만들어줘 ✍️ 블로그 글 써줘 🐍 파이썬 코드 만들어줘
왜 중요한가요? — 실전 비교
구분프롬프트 예시결과
❌ 단순강아지 그림 만들어줘평범함 · 품질 불안정
✅ 엔지니어링노을지는 바닷가에서 뛰어노는 흰색 강아지, 영화 조명, 따뜻한 감성, 실사 스타일분위기·감정·영화 같은 이미지
핵심 공식
BASIC FORMULA
목적 + 대상 + 분위기 + 스타일 + 길이/품질
💬 예시: "초보자를 위한 친절한 AI 강의 교재를 전문적이지만 쉽게, A4 3장 분량으로 작성"
초보자가 가장 많이 하는 실수 3가지
❌ "멋지게 만들어줘"
✅ 원하는 스타일·분위기를 구체적으로 설명
❌ 실사인지 애니메이션인지 미입력
✅ 실사/애니/감성/SF 등 명시
❌ 어린이용·전문가용 구분 안 함
✅ 어린이·어르신·학생·전문가 명시
초보자 프롬프트 작성 4단계
1
무엇을 만들지 결정 — 글 / 이미지 / 영상 / 음악 / 코드
2
분위기 정하기 — 감성적 / 미래적 / 따뜻한 / 슬픈 / 웅장한
3
스타일 정하기 — 영화 / 실사 / 애니메이션 / 수채화 / 광고풍
4
세부 요소 추가 — 조명 · 카메라 · 감정 · 색감 · 움직임

CHAPTER 7AI 카드뉴스 제작 프롬프트
카드뉴스란?
정보를 짧고 시각적으로 전달하는 SNS 콘텐츠 형식. 보통 5~10장 카드로 구성되며, 핵심 문장 + 간단한 설명이 들어갑니다.
📸 인스타그램📝 블로그 💬 카카오채널🎬 유튜브 커뮤니티 👥 밴드

주제 + 대상 + 장 수 + 톤&분위기 + 디자인 스타일 + 플랫폼
